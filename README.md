# A/B-тест email-рассылки: анализ и uplift-модель

Анализ реального A/B-теста интернет-магазина (датасет Hillstrom Email Marketing): проверка гипотез, сегментный анализ и uplift-модель, которая подсказывает, каким клиентам письмо действительно помогает.

## Данные
[Hillstrom Email Marketing](https://www.kaggle.com/) (64 000 клиентов, три группы: письмо с мужской подборкой, письмо с женской подборкой, без письма). Файл в репозиторий не включён, его нужно скачать с Kaggle.

## Структура
- `notebooks/` — анализ
- `sql/` — запросы для дашборда

## Результаты
Будут добавлены после завершения анализа.
